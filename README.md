# ExamIQ


**Learn by exploring, predicting, and experimenting.**

ExamiQ is an offline-first interactive learning project designed to help students develop conceptual understanding through experimentation, prediction, and active recall rather than relying only on passive reading.

## Current Demo

The current prototype focuses on **Projectile Motion**, a Class 11 Physics topic.

### How it works

ExamiQ is organised into three connected layers:

1. **Discovery Hub** — Explore the learning platform.
2. **Physics Hub** — Navigate to the available Physics topic.
3. **Interactive Lesson** — Explore Projectile Motion through the learning experience.

## Features

- Three-layer navigation between the homepage, Physics hub, and lesson.
- Interactive Physics learning experience.
- Responsive interface designed for desktop and mobile.
- Offline-oriented design.

*Offline behaviour and individual features should be verified against the current build and its actual requirements.*

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Navigate to Physics and select Projectile Motion.

If the browser restricts any functionality when opening files directly, serve the project locally using a static development server.
